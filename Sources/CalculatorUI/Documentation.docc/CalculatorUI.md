swift-calculator is a swift package that provides an inline calculator with SwiftUI API.

## Additional Resources

- [GitHub Repository](https://github.com/cybozu/swift-calculator)

## Overview

This package provides an inline calculator interface for SwiftUI. It supports arithmetic operations and modulo operations, and the calculator view binds the settled result as a decimal value. Furthermore, it provides a method for building custom views using only the core system of operations.
